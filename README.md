# Cognifyz Web Development Internship

## 📌 About the Project

This repository contains my work completed during the
Cognifyz Technologies Web Development Internship.

The project demonstrates my skills in HTML, CSS, JavaScript,
Bootstrap, and responsive web design.

## 🎯 Internship Tasks Completed

### Level 1: HTML, CSS and JavaScript

- Created a webpage with heading, paragraph, and image.
- Developed a basic form with input field and submit button.
- Created a navigation menu with three links.
- Implemented a button that changes color when clicked.
- Created a time-based greeting using JavaScript.
- Developed a basic calculator to add two numbers.

### Level 2: Front-End Frameworks and Responsive Design

#### Task 1: Front-End Frameworks

- Integrated Bootstrap into the webpage.
- Created a responsive card component with image and text.
- Implemented a responsive grid layout.
- Added project cards using Bootstrap.

#### Task 2: Responsive Design

- Added CSS media queries for different screen sizes.
- Created a mobile-friendly navigation menu.
- Implemented a hamburger menu for smaller screens.
- Added responsive styling for webpage elements.
